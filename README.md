## 概要

このリポジトリでは、サイバーセキュリティに関する最新のニュースやトピックをキュレーションし、整理して掲載しています。

## 作成にあたって

- 収集にあたって，なるべく1次ソースを追うようにしています。
- 主に収集するニュース
  + 日本との関係が強いと考えられるニュース
  + 攻撃者の動向（攻撃手法，狙いなど）
- あまり収集しないニュース
  + 製品の脆弱性情報

## コンテンツ構成

- ページタイトル
- サマリー（日本語）
- タグ
- 収集日
- ページURL

## 免責事項

当リポジトリは情報提供を目的としており、記載された内容の正確性・完全性を保証するものではありません。
本リポジトリに掲載した内容は予告なく変更することがあります。

# 2026年2月 サイバー脅威動向レポートサマリー
## 1. AI技術に関連する攻撃と悪用

* Offensive AI：フィッシングサイトが急増。AIを活用することによるとみられる。
* AI for Security: 脆弱性の報告が急増。パッチの適用に課題。

## 2. 国家支援型攻撃
* ニュースで取り上げられている攻撃は，既知の手法を用いるケースが多い。

## 3. 一般社員向け
* マルチステージの高度なフィッシングが複数報告。メジャーではないものの，MFAを回避するサイトも一部で確認されている状況。

## 4. 開発者向け
* OpenAIがAIを活用した脆弱性検出およびパッチ検証ツール「Daybreak」を発表
* 悪意あるSkillsや偽のAIサービス等，AIを用いた開発者を狙った攻撃が引き続き活発。
